```
PulseUX mide la satisfacción de tus clientes en el instante exacto en que ocurre la experiencia.

Es un dispositivo de tres botones que se instala a la salida de tu establecimiento. El cliente pulsa uno, una luz confirma el registro y el dato llega a tu panel en tiempo real. Toma menos de tres segundos, no requiere aplicación y no solicita datos personales.

Pensado para retail, restaurantes, clínicas, entidades financieras y cualquier organización con atención presencial en Lima Metropolitana.

Un toque. Un dato. Una decisión.
```

## Sección 5 — Por qué PulseUX

**Titular:**
```
Lo que ninguna encuesta digital puede ofrecerte
```

**Diferenciador 1**
```
No pide datos personales
El sistema registra solo la opción elegida, el dispositivo y la hora. No captura nombres, correos ni documentos de identidad, de modo que queda fuera del ámbito de la Ley 29733 de Protección de Datos Personales. Sin consentimientos que gestionar ni riesgos de cumplimiento.
```

**Diferenciador 2**
```
No requiere aplicación
Funciona con cualquier cliente, tenga o no un smartphone a la mano. Nada que descargar, nada que escanear, ningún enlace que abrir. El dato que recoges representa a toda tu clientela, no solo a la parte digitalmente activa.
```

**Diferenciador 3**
```
Menos de tres segundos
El 68 % de las personas está dispuesto a dedicar quince segundos o menos a dar su opinión al salir de un establecimiento. PulseUX necesita tres.
```

# PulseUX_WEB

Página web comercial de PulseUX: presenta la propuesta de valor a un comprador B2B y aloja
un simulador del dispositivo conectado a un dashboard real.

## Levantar `web/` en local

```
cd web
npm install
npm run dev
```
